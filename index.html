01 / Motivation

Introduction

Reading a chart means understanding where things are and what they represent.

Charts combine a structured visual layout with an underlying data representation. A model must locate the right subplot, axis, or legend before it can reliably interpret the values and answer a question. START brings these two properties into training through chart-element grounding and chart-to-code generation, alongside chart question answering.

We introduce START-Dataset to support this learning and CS-Bench to evaluate how well models understand chart structure. This page highlights the publicly released, reproduced dataset, benchmark, and checkpoint.

02 / Training resource

START-Dataset

Real chart complexity. Executable code. Spatial supervision.

The data-generation pipeline starts from real chart images and reconstructs them as Python code. It then evolves that code to extract chart-element locations during rendering. Together with question-answer pairs, these annotations connect visual layout to the data represented in each chart.

03 / Evaluation resource

CS-Bench

Can a model locate the evidence behind its answer?

The Chart Spatial understanding Benchmark tests a capability that answer-only evaluation does not directly measure: identifying and localizing chart structure. It includes titles, axis labels and ticks, legends, subplots, and inset subplots.

600unique images

Chart-element grounding

Locate a specified visual element and return its bounding-box coordinates.

“Locate the name of the y-axis of subplot in row 1 and column 1, output its bbox coordinates using JSON format.”

342 questions · 49.42%

QA grounding

Answer a question about a chart element and identify the relevant region. This tests whether the answer is connected to the correct visual structure.

Questions link textual content with its location in the chart, so answer correctness and localization can be assessed separately.

Evaluates answers + localization

How is it evaluated?

Recall@0.3 measures localization at an intersection-over-union (IoU) threshold of 0.3. Answer accuracy measures correctness on QA-grounding questions. The provided evaluator also reports Recall@0.5.

04 / Learning framework

Method Overview

Teach the model to answer, locate, and reconstruct.

START combines chart question answering with two complementary training tasks. The framework studies both supervised fine-tuning and reinforcement learning to strengthen chart understanding.

Spatial learning

Chart-element grounding

Predict the location of the element described by an instruction. Explicit spatial supervision connects language to chart layout.

chart + instruction → coordinates
Textual learning

Chart-to-code generation

Generate executable Python that reconstructs the chart. Code represents data values and how those values are visualized.

chart + instruction → Python
Chart understanding

Question answering

Use both spatial structure and textual details to answer questions about the chart.

chart + question → answer

See Section 3.1 of the paper for the learning objectives and reward design.
